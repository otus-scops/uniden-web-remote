# BCT15X メモリエディタ機能 (FreeSCAN代替) 実装完了ウォークスルー

## 概要
BCT15Xの実機プロトコル（DMAリンクリスト構造: `SIH`, `SIN`, `GIH`, `GIN`, `CIH`, `CIN`等）を完全実装し、スキャナー本体の全メモリデータを正確に読み書きできるようになりました。
また、Web UI上にFreeSCANの操作性を代替する**本格スプレッドシート型チャンネルエディタ**、**システム/グループ階層ツリー**、**Excelからの複数行一括貼り付け**、**安全な自動バックアップ＆復元機能**、**CSV/JSON入出力**を構築しました。

---

## 主な実装機能

### 1. BCT15X DMAプロトコル通信 (バックエンド)
- [dmaProtocol.js](file:///m:/%E3%83%9E%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%96/Uniden/Remote%20for%20docker/src/scanner/dmaProtocol.js)
  - `SIH` (System Head) から `FWD_INDEX` を辿る全システム走査
  - `CHN_GRP_HEAD` から `FWD_INDEX` を辿る全グループ走査 (`GIN`)
  - `CHN_HEAD` から `FWD_INDEX` を辿る全チャンネル走査 (`CIN`)
  - 8桁生周波数（`01181000`）とMHz表記（`118.1000`）の双方向変換
  - CTCSS / DCS コード表（0〜231）とトーン名（`CTCSS 88.5Hz`, `DCS 023`）の双方向変換
- [programmingController.js](file:///m:/%E3%83%9E%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%96/Uniden/Remote%20for%20docker/src/scanner/programmingController.js)
  - `getAllMemory()`: 実機から全階層を漏れなく取得するダウンロード処理
  - `uploadAllMemory()`: 実機への一括書き込み処理（**書き込み前に自動でローカルバックアップJSONを作成**）
- [memoryRoutes.js](file:///m:/%E3%83%9E%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%96/Uniden/Remote%20for%20docker/src/api/memoryRoutes.js)
  - `/api/memory/all` (GET/POST): 全メモリ送受信
  - `/api/memory/progress`: 通信進捗ポーリング
  - `/api/memory/backups`: 自動バックアップファイル一覧および復元エンドポイント
  - `/api/memory/export/csv` & `/api/memory/import/csv`: FreeSCAN親和性の高いCSVインポート/エクスポート

### 2. FreeSCANライクな本格エディタUI (フロントエンド)
- [index.html](file:///m:/%E3%83%9E%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%96/Uniden/Remote%20for%20docker/public/index.html) & [memoryEditor.js](file:///m:/%E3%83%9E%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%96/Uniden/Remote%20for%20docker/public/js/memoryEditor.js)
  - **エディタツールバー**:
    - `📥 スキャナーから読込`: 実機から全メモリを取得し、プログレスバーで進捗表示
    - `📤 スキャナーへ書込`: 編集内容を実機へ書き込み（事前バックアップ付き）
    - `📂 JSON読込` / `💾 JSON保存`: ローカルファイル保存・読み込み
    - `📊 CSV読込` / `📊 CSV保存`: 表計算ソフトとの連携
    - `🛡️ バックアップ履歴`: 過去の自動バックアップ一覧からのワンクリック復元
  - **左ペイン (ツリーナビゲーション)**:
    - システム（CNV/MOT等）、グループの階層表示
    - クイックキー（Q:1等）やチャンネル数バッジの表示
    - ノードの追加・名前変更・削除
  - **メインペイン (チャンネルスプレッドシート)**:
    - チャンネル名、周波数、変調（AUTO/AM/FM/NFM/WFM）、トーン/コード、L/O、PRI、ATTのインライン編集
    - 行追加、行複製（📄）、行削除（🗑️）
  - **Excel / テキストからの一括貼り付け機能**:
    - ExcelやGoogleスプレッドシートでコピーした表（TSV/CSV）をモーダルに貼り付けるだけで、一度に数十〜数百チャンネルを一括取り込み可能
  - **プログレスモーダル**:
    - 実機との通信中にパーセントと現在の処理内容をリアルタイム表示

## 画面イメージと操作フロー

1. 画面右上の **「📝 エディタ起動」** をクリックすると、スキャナー表示からエディタ画面に切り替わります。
2. 上部ツールバーの **「📥 スキャナーから読込」** を押すと、BCT15X本体のメモリデータが読み込まれます。
3. 左側のツリーからグループを選択すると、右側にチャンネル一覧がスプレッドシート表示されます。
4. 周波数やチャンネル名を直接修正したり、「➕ 行追加」や「📋 Excel貼り付け」で素早く登録できます。
5. 編集完了後、**「📤 スキャナーへ書込」** を押すと、自動で安全バックアップが取得された上で実機に反映されます。
